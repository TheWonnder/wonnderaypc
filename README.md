# Wonnderay для Windows

VPN-клиент на VLESS/Xray. Те же подписки и серверы, что на телефоне, плюс то,
что имеет смысл только на компьютере.

## О приложении

- **Два режима.** «Прокси» поднимает SOCKS5/HTTP на `127.0.0.1` и прописывает
  их в системные настройки Windows — работает **без прав администратора**, и
  Chrome, Edge и большинство приложений подхватывают его сами. «Туннель» —
  полноценный TUN-адаптер, через него идёт весь трафик системы; вот он права
  запросит, но только в тот момент, когда его включают.
- **Подписки и серверы** — список с пингом, избранное, поиск, сортировка,
  выбор лучшего сервера по результатам замера.
- **Локальный прокси** можно раздать в локальную сеть — например, на телевизор
  или консоль. Приложение прямым текстом предупреждает, что это открытый релей
  без пароля.
- **Маршрутизация.** Обход для локальной сети, для `.ru` и `.рф`, свой список
  доменов напрямую.
- **Kill switch.** Если ядро упадёт, трафик блокируется правилом брандмауэра, а
  не уходит мимо туннеля.
- **Значок в трее** — состояние, подключение и выход. Пока он включён, закрытие
  окна прячет приложение, а не рвёт соединение.
- **Обновляется само:** проверяет релизы при запуске, качает установщик в фоне
  и спрашивает о перезапуске. Молча не перезапускается — перезапуск роняет
  туннель.
- **Протоколы:** VLESS поверх TCP / WS / gRPC / XHTTP, TLS и Reality.
- Русский и английский, Windows 10 и 11.

Приложение ничего не имитирует: «Подключено» загорается только после живого
ядра и поднятого маршрута, счётчики трафика читаются из ядра, а пинг
показывает измеренное значение либо честный прочерк.

## Скачать

Актуальная версия — на вкладке [Releases](../../releases/latest).

| Файл | Что это |
| --- | --- |
| `Wonnderay-<версия>-setup.exe` | Установщик |
| `Wonnderay-<версия>-win.zip` | То же без установки, портативно |
| `latest.yml`, `*.blockmap` | Служебные файлы автообновления — вручную не нужны |

Установщик не подписан, поэтому при первом запуске SmartScreen покажет
«Windows защитила ваш компьютер»: «Подробнее» → «Всё равно выполнить».
Сертификат для подписи кода выдаётся на организацию или ИП и стоит денег —
отсюда предупреждение.
