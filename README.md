## Что это

Wonnderay подключает компьютер к **вашему собственному** серверу и пропускает
через него трафик. Своих серверов у приложения нет и не продаётся ничего: вы
даёте ему ссылку `vless://` или адрес подписки, выданный панелью, а оно делает
остальное — хранит список, меряет задержку, поднимает туннель и переписывает
маршруты системы.

## Возможности

| Что умеет | Подробности |
| --- | --- |
| **Два режима** | **Прокси** поднимает SOCKS5/HTTP на `127.0.0.1` и прописывает их в настройки Windows — работает **без прав администратора**, Chrome, Edge и большинство программ подхватывают его сами. **Туннель** — полноценный TUN-адаптер, через него идёт весь трафик машины; права он спросит, но только в тот момент, когда его включают. |
| **Обход по приложениям** | Выбранные программы ходят мимо туннеля — или, наоборот, только они в него и попадают. Правило переживает обновление программы: Discord и всё на Squirrel заводят новую папку на каждую версию, и точный путь после обновления не совпал бы ни с чем — молча. |
| **Подписки и серверы** | Список с пингом, избранное, поиск, сортировка, автообновление у каждой подписки по своему расписанию, свой экран подписки с интервалом и сроком. |
| **Лучший сервер** | Одна кнопка: гасит туннель, меряет весь список и поднимается на победителе. |
| **Проверка под нагрузкой** | Отдельно от пинга: шестнадцать одновременных запросов через сервер. Она отвечает на другой вопрос — выдержит ли сервер страницу, а не сколько идёт один запрос. Сервер может честно показывать 170 мс и терять треть соединений, и в браузере это выглядит как `ERR_SSL_PROTOCOL_ERROR`. |
| **Локальный прокси в сеть** | Раздать туннель телевизору или консоли. Приложение прямым текстом предупреждает, что это открытый релей без пароля. |
| **Kill switch** | Упало ядро — трафик блокируется правилом брандмауэра, а не уходит мимо туннеля. |
| **Значок в трее** | Состояние, подключение и выход. Пока он включён, закрытие окна прячет приложение, а не рвёт соединение. |
| **Обновляется само** | Проверяет релизы при запуске. Загрузка начинается **только с кнопки** — десятки мегабайт по чужому мобильному интернету не качаются без спроса, — а установка идёт сразу за ней, в окне самого приложения, а не в системном диалоге. |
| **Оформление** | Чёрный OLED-фон, обои, акцент из картинки. Русский, английский и муринский. |

## Скачать

Актуальная версия — на вкладке **[Releases](../../releases/latest)**.

| Файл | Что это |
| --- | --- |
| `Wonnderay-<версия>-setup.exe` | **Установщик — берите его** |
| `Wonnderay-<версия>-win.zip` | То же без установки, портативно |
| `latest.yml`, `*.blockmap` | Служебные файлы автообновления, вручную не нужны |

Установщик не подписан, поэтому при первом запуске SmartScreen покажет
«Windows защитила ваш компьютер»: **«Подробнее» → «Всё равно выполнить»**.
Сертификат для подписи кода выдаётся на организацию или ИП и стоит денег —
отсюда предупреждение.
