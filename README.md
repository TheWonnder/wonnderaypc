# Wonnderay — сборки

Здесь лежат только готовые сборки. Исходный код Wonnderay в этот репозиторий
не попадает и попасть не должен.

## Скачать

Актуальная версия — на вкладке [Releases](../../releases/latest).

| Файл | Что это |
| --- | --- |
| `Wonnderay-<версия>-setup.exe` | Установщик для Windows |
| `Wonnderay-<версия>-win.zip` | То же без установки, портативно |
| `latest.yml`, `*.blockmap` | Служебные файлы автообновления — скачивать вручную не нужно |

Приложение обновляется само: проверяет этот репозиторий при запуске, качает
установщик в фоне и спрашивает о перезапуске. Отдельно ходить сюда за
обновлением не требуется.

## Почему репозиторий отдельный

Автообновлению нужна открытая лента релизов: клиент без токена должен видеть
`releases/latest`. У приватного репозитория GitHub отвечает такому клиенту
`404`, и обновление не приходит никому.

Решать это токеном, вшитым в приложение, нельзя. Токен, положенный внутрь
`.exe` или `.apk`, читается любым, у кого есть файл, а токен с правом
`Contents: read` — это доступ ко всему дереву исходников, а не только к
релизам.

Поэтому репозитория два: исходники приватные, сборки публикуются сюда, и
токен не нужен вообще.

## Как сюда попадают файлы

Только через GitHub Releases API — `gh release` и публикатор electron-builder.
У рабочей копии исходников нет git-remote на этот репозиторий, так что
запушить сюда код нечем: залить можно ассет к релизу, но не ветку.
