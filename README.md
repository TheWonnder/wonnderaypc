# Wonnderay для Windows — сборки

Здесь лежат только готовые сборки. Исходный код Wonnderay в этот репозиторий
не попадает и попасть не должен.

## Скачать

Актуальная версия — на вкладке [Releases](../../releases/latest).

| Файл | Что это |
| --- | --- |
| `Wonnderay-<версия>-setup.exe` | Установщик |
| `Wonnderay-<версия>-win.zip` | То же без установки, портативно |
| `latest.yml`, `*.blockmap` | Служебные файлы автообновления — вручную не нужны |

Приложение обновляется само: проверяет этот репозиторий при запуске, качает
установщик в фоне и спрашивает о перезапуске.

Установщик не подписан, поэтому SmartScreen предупредит при первом запуске:
«Подробнее» → «Всё равно выполнить».

## Почему репозиторий отдельный

Автообновлению нужна открытая лента релизов: клиент без токена должен видеть
`releases/latest`. У приватного репозитория GitHub отвечает такому клиенту
`404`, и обновление не приходит никому — молча, без ошибки.

Решать это токеном, вшитым в приложение, нельзя. Токен внутри `.apk` или
`.exe` читается любым, у кого есть файл, а токен с правом `Contents: read`
открывает всё дерево исходников, а не только релизы.

## Почему у каждой платформы свой

Лента у GitHub одна на репозиторий, и «последний релиз» — тоже один.
Обновлялка Android ищет в нём APK, обновлялка Windows — `latest.yml`. Лежи
они вместе, каждый новый релиз одной платформы прятал бы обновления от другой:
не с ошибкой, а с уверенным «у вас последняя версия». Поэтому репозиториев
три — по одному на платформу:

| Платформа | Репозиторий |
| --- | --- |
| Android | [wonnderay4a](https://github.com/TheWonnder/wonnderay4a) |
| Windows | [wonnderaypc](https://github.com/TheWonnder/wonnderaypc) |
| iOS | [wonnderayios](https://github.com/TheWonnder/wonnderayios) |

## Как сюда попадают файлы

Только через GitHub Releases API. У рабочей копии исходников нет git-remote на
этот репозиторий, так что запушить сюда код нечем: залить можно ассет к
релизу, но не ветку.
